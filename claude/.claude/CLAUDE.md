# Global Claude Instructions

## Git Commit Guidelines
- Never attribute yourself in git commits unless explicitly asked to in that message. This applies to all projects.
- Always use the Conventional Commits format.
- Format: `<type>(<optional scope>): <description>`
- Use types like `feat`, `fix`, `refactor`, `docs`, `chore`, `style`, `test`, or `perf`.
- Write the description in the imperative mood (e.g., "add login button" instead of "added login button").
- Add a multi-line body explaining the "why" if the change is complex.
- Example: `feat(auth): add google oauth login`

## Superpowers

Never commit superpower docs unless explicitly asked to in that message. This applies to all projects.
